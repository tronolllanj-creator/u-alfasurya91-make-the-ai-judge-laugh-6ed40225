# Make the AI Judge Laugh

This program generates a single, humorous one-liner about office life
and writes it to entry.txt for the make.fun bounty
u-alfasurya91-make-the-ai-judge-laugh-6ed40225.

Bounty page: https://make.fun/bounty/u-alfasurya91-make-the-ai-judge-laugh-6ed40225

## How to Run
Execute the following command with output directory configured:

MAKEFUN_OUTPUT_DIR=out node main.ts

## Output Format
The generated joke must be a single line and between 1-200 characters.
